# Frontend «Помощника агронома»

Next.js-приложение с тремя вкладками: диагностика, справочник, полевой журнал. Диагностика работает в браузере через ONNX Runtime Web; отдельного сервера распознавания нет.

Этот каталог нужно использовать как рабочую директорию всех npm-команд ниже. Общий реестр классов расположен уровнем выше, в `../config/`: при переносе frontend его также нужно сохранить.

## Окружение

| Компонент | Версия / назначение |
|---|---|
| Node.js | Рекомендуется 24.x, как в настройках Vercel |
| Next.js | 14.2.35 в lock-файле |
| React | 18.x |
| TypeScript | Типизация приложения |
| Tailwind CSS | 3.x |
| ONNX Runtime Web | Строго 1.30.0 |
| Vitest / Playwright | Unit / браузерные проверки |

Точные зависимости устанавливаются через `package-lock.json`, поэтому использовать `npm ci`. Ключи внешнего AI API, `DATABASE_URL` и Python для сайта не требуются. Камера и браузерные API требуют HTTPS либо доверенного localhost; сайт может предложить выбор файла вместо камеры в зависимости от устройства.

## Установка и разработка

Из корня репозитория:

```powershell
cd frontend
npm ci
npm run prepare:model
npm run dev
```

Сайт: [localhost:3000](http://localhost:3000). `prepare:model` проверяет ONNX/метаданные и копирует runtime из установленного `onnxruntime-web` в `public/ort/1.30.0/`. При отсутствии исходных файлов он скачивает закреплённые ревизии. Веса не загружаются браузером до начала анализа.

## Production-сборка локально

Остановить dev-сервер, затем:

```powershell
npm run build
npm run start -- --hostname 127.0.0.1 --port 3001
```

`build` уже включает `prepare:model`. `start` требует готовый `.next`. При изменении файлов `public/` или модели повторить сборку перед проверкой production. Одновременные `next dev` и `next build/start` в одном checkout могут повреждать общий `.next`.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Dev-сервер Next.js |
| `npm run build` | Подготовка модели и production-сборка |
| `npm run start` | Запуск готовой production-сборки |
| `npm run prepare:model` | Подготовка и проверка закреплённого модельного пакета |
| `npm test` | Структура каталога, файлы, соответствие классов |
| `npm run test:unit` | Unit-тесты Vitest |
| `npm run test:e2e` | Все Playwright-сценарии |
| `npm run test:model` | Node-проверка пакета/отчёта и браузерный model-smoke |
| `npm run evaluate:model` | Полный benchmark; перезаписывает отчёты, см. [testing](../docs/testing.md) |
| `npm run lint` | Штатный `next lint`; готовой конфигурации ESLint в репозитории нет, возможен интерактивный запрос |
| `npx tsc --noEmit` | Проверка типов без генерации JS |

Для Playwright предварительно выполнить `npx playwright install chromium`. Обычный `npm test` не запускает unit и E2E.

## Параметры и данные

- `PLAYWRIGHT_BASE_URL`: URL уже запущенного сайта для тестов; отключает автоматический dev-сервер Playwright.
- `EVIDENCE_DIR`: каталог скриншотов для сценариев, которые поддерживают эту переменную.
- `NODE_EXTRA_CA_CERTS`: путь к доверенному дополнительному CA, если того требует корпоративная сеть. Проверка TLS должна оставаться включённой.
- Порогов и реестра классов в `.env` нет: это версионируемые исходники, описанные в [recognition](../docs/recognition.md).

`localStorage` хранит журнал под ключом `agronomist_field_journal_v1`; версия отдельных записей — 2. Cache Storage хранит модельные ресурсы. Очистка данных сайта удаляет локальную историю и кэш. При смене домена они автоматически не переносятся.

## Частые проблемы

| Симптом | Проверка / действие |
|---|---|
| `next` или `onnxruntime-web/dist` не найден | Выполнить `npm ci` именно в `frontend/` |
| 404 для ONNX, Worker или WASM | Выполнить `npm run prepare:model`, проверить `public/`, пересобрать сайт |
| `Integrity check failed` | Восстановить исходный файл закреплённой ревизии; не подгонять SHA в manifest под повреждённый файл |
| Модель не запускается | Проверить доступ к файлам, поддержку WASM/Worker, консоль и сеть; повторить в актуальном браузере |
| Фото отвергается до анализа | Проверить MIME JPEG/PNG/WebP, размер до 10 МиБ, разрешение до 20 Мп; HEIC/SVG не принимаются |
| Журнал не сохраняется | Проверить квоту и доступность `localStorage`, удалить ненужные записи средствами UI |
| Исчезла история после перехода по новой ссылке | Вернуться на прежний домен в том же браузере: хранилища разных origin раздельны |
| 404 JS-чанков после тестов/сборки | Остановить конфликтующие Next.js-процессы, удалить только генерируемый `frontend/.next`, выполнить сборку заново |
| Playwright не находит браузер | `npx playwright install chromium` |
